# tenki

渋川市石原の「屋外の暑さと天気」を壁掛けテレビに表示するためのページです。

- 公開ページ：https://k-tomitsuka.github.io/tenki/
- 表示内容：気温・湿度・天気・風・暑さ指数（WBGT）、12時間の予報（表とグラフ）、明日・明後日の予報、気象庁の警報・注意報、行事（安全週間など）
- 更新履歴：[CHANGELOG.md](CHANGELOG.md)
- 過去の版：`archive/` フォルダ（ファイル名は並び順をそろえるため v1.09 のように小数点以下2桁。画面の版番号 v1.9 と同じもの）
- データの出典：気象庁、Open-Meteo（CC BY 4.0）

## 設定の変え方

設定は `index.html` の先頭近くにある `const CONFIG = {` から `};` までにまとまっています。
GitHubで `index.html` を開き、右上の鉛筆（Edit this file）で数字や文字を書き換え、「Commit changes...」で保存すると反映されます（テレビは最長6時間で自動再読込。すぐ反映したいときはリモコンで「Load Start URL」）。

書き換えるときの注意：数字と文字以外（カンマ、引用符、かっこ）は変えないでください。1文字欠けると画面が真っ暗になります。心配なときは、先に `archive/` の最新版をPCに保存しておけば戻せます。

| 変えたいこと | 行 | 例 |
|---|---|---|
| 注意喚起のしきい値 | `alerts: {tempHigh:35, tempLow:3, rhLow:30, windWarn:5}` | 高温35℃以上／凍結3℃以下／乾燥30％以下／強風5m/s以上。強風を7m/sにするなら `windWarn:7` |
| WBGTを表示しうる期間 | `wbgtSeason: ['04-20','10-31']` | 4月20日〜10月31日。この外は右端の枠が常に体感温度 |
| WBGTを常に表示する期間 | `wbgtAlways: ['06-01','08-31']` | 6〜8月は涼しい日もWBGT |
| WBGTと体感温度の切り替え基準 | `wbgtShowFrom: 21` | 上の2つ以外の時期（春・秋）は、これから12時間でWBGTが21（注意）以上になるときだけWBGT、ならなければ体感温度 |
| 行事の表示 | `campaigns: [ ... ]` | 1行が1つの行事。`from`/`to` は月-日（`'12-15'` から `'01-15'` のように年またぎ可）。外したい行事は行ごと消す。追加は同じ形で1行足す |
| 日の出・日の入り／明日・明後日 | `showSun: true` / `showDays: true` | 消したいときは `false` |
| レーダー観測／今後の雨 | `radar: true` / `rainForecast: true` | 気象庁の画像を使わず予報モデルだけにするなら `false` |
| 夜間の減光 | `dimNight: [22, 5], dimLevel: 0.75` | 22時〜5時に明るさ75％。減光をやめるなら `dimLevel: 1` |
| 背景を夜扱いにする時刻 | `skyNight: [18, 5]` | 通常は日の出・日の入りで自動判定。取得できないときの予備 |
| 更新のタイミング | `refreshMinute: 5` / `dailyReloadHour: 3` | 毎時5分に更新、毎日3時台に再読込 |
| 右端の枠の文字揃え | `wbgtAlign: 'center'` | 左揃えにするなら `'left'` |
| 更新停止の表示 | `staleHours: 6` | 6時間以上更新できないと画面中央に表示 |
| 地点 | `placeName`, `lat`, `lon` | 別の場所に置くときは地名と緯度・経度を変える（気象庁の区域・市町村コード `jmaArea`, `jmaCity` も合わせて変更） |
| 版番号 | `version: '1.13'` | 画面右下に出る番号。差し替えのたびに上げる |

## 画面の確認用（URLの末尾に付ける。本番のURLには付けない）

- `?test=30` … WBGTの値を仮に30にして色を確認（WBGTは上段・表とも小数第1位を四捨五入した整数で表示・判定）
- `?wx=rain` … 天気を仮に雨にして背景を確認（sun / partly / cloud / fog / rain / snow / thunder）
- `?season=winter` … 冬季モード（体感温度）の見え方
- `?warn=14,15` … 雷注意報・強風注意報が出たときの見え方（数字は気象庁のコード）
- `?alert=1` … 注意喚起のバッジを全部表示
- `?radar=0` … 「現在」にレーダー観測の小雨を表示（1なら1〜5mm）

## 画面右下の点（管理者向けの自己診断）

緑の点4つが正常。左から「予報・警報・レーダー・今後の雨」。一定時間取得できていないものは赤い点と名前で出ます（予報・警報は3時間、レーダーは20分、今後の雨は90分）。名前が赤く出続けるときは、ネット回線か、気象庁側のデータの形式変更が考えられます。
