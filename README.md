# tenki

渋川市石原の「屋外の暑さと天気」を壁掛けテレビに表示するためのページです。

- 公開ページ：https://k-tomitsuka.github.io/tenki/
- 表示内容：気温・湿度・天気・風・暑さ指数（WBGT）、12時間の予報（表とグラフ）、明日・明後日の予報、気象庁の警報・注意報、行事（安全週間など）
- 更新履歴：[CHANGELOG.md](CHANGELOG.md)
- 過去の版：`archive/` フォルダ（ファイル名は並び順をそろえるため v1.09 のように小数点以下2桁。画面の版番号 v1.9 と同じもの）
- データの出典：気象庁、Open-Meteo（CC BY 4.0）。通常・予備の配信元に届かないときだけ MET Norway（ノルウェー気象研究所、CC BY 4.0）

## 設定の変え方

設定は `index.html` の先頭近くにある `const CONFIG = {` から `};` までにまとまっています。
GitHubで `index.html` を開き、右上の鉛筆（Edit this file）で数字や文字を書き換え、「Commit changes...」で保存すると反映されます。

テレビへの反映：`version` の番号も上げて保存すれば、約1時間以内に自動で切り替わります（v1.19以降）。番号を上げなかったときは、毎朝3:30台の読み直しか、最長12時間ごとの自動再読込で切り替わります。

書き換えるときの注意：数字と文字以外（カンマ、引用符、かっこ）は変えないでください。v1.19以降のテレビは、自動の切り替えのときに文法エラーのある版を見つけると読み込まず（右下に「新しい版に誤りあり」と出ます）、今の版で表示を続けます。ただしテレビの再起動や12時間ごとの自動再読込では、公開中の版をそのまま読み込みます。そのとき画面が「--」のまま動かなければ、直した index.html を上書きすれば10分ほどで自動的に戻ります。心配なときは、先に `archive/` の最新版をPCに保存しておけば戻せます。

| 変えたいこと | 行 | 例 |
|---|---|---|
| 注意喚起のしきい値 | `alerts: {tempHigh:35, tempLow:3, rhLow:30, windWarn:5}` | 高温35℃以上／凍結3℃以下／乾燥30％以下／強風5m/s以上。強風を7m/sにするなら `windWarn:7` |
| WBGTを表示しうる期間 | `wbgtSeason: ['04-20','10-31']` | 4月20日〜10月31日。この外は右端の枠が常に体感温度 |
| WBGTを常に表示する期間 | `wbgtAlways: ['06-01','08-31']` | 6〜8月は涼しい日もWBGT |
| WBGTと体感温度の切り替え基準 | `wbgtShowFrom: 21` | 上の2つ以外の時期（春・秋）は、これから12時間でWBGTが21（注意）以上になるときだけWBGT、ならなければ体感温度 |
| 行事の表示 | `campaigns: [ ... ]` | 1行が1つの行事。`from`/`to` は月-日（`'12-15'` から `'01-15'` のように年またぎ可）。外したい行事は行ごと消す。追加は同じ形で1行足す |
| 体感温度の色 | `coldBands: [ ... ]` | 6段階の色（社内の目安）。`min` は「この値以上」、`bg` は色。段階の数や色は行ごとに変更可 |
| 表の「体感」行の色 | `tintColdRow: true` | 色を付けないなら `false` |
| 日の出・日の入り／明日・明後日 | `showSun: true` / `showDays: true` | 消したいときは `false` |
| レーダー観測／今後の雨 | `radar: true` / `rainForecast: true` | 気象庁の画像を使わず予報モデルだけにするなら `false` |
| 夜間の減光 | `dimNight: [22, 5], dimLevel: 0.75` | 22時〜5時に明るさ75％。減光をやめるなら `dimLevel: 1` |
| 背景を夜扱いにする時刻 | `skyNight: [18, 5]` | 通常は日の出・日の入りで自動判定。取得できないときの予備 |
| 更新のタイミング | `refreshMinute: 5` / `dailyReloadHour: 3` | 毎時5分に更新、毎日3時台に再読込 |
| 右端の枠の文字揃え | `wbgtAlign: 'center'` | 左揃えにするなら `'left'` |
| ネットにつながらないときの表示 | `staleHours: 2` | テレビがどこにもつながらない状態が2時間続くと、画面中央に「最新の情報ではありません」と最後の更新時刻を表示 |
| 配信元だけ止まったときの表示 | `staleSourceHours: 24` | 回線は正常で予報の配信元だけ止まっているときは、手元の予報が24時間より古くなるまで、ふつうに表示を続ける（超えたら上と同じ表示） |
| 再試行の間隔 | `retrySteps: [0.5, 1, 2, 5]` | 予報の取得に失敗したとき、30秒 → 1分 → 2分 → 以後5分ごとに取り直す（単位は分） |
| 予備の配信元 | `fallbackApi: true` | 通常の配信元に届かないとき、Open-Meteoの別サーバーから同じ予報を取る。使わないなら `false` |
| 予備2の配信元 | `metnoApi: true` | 通常・予備の両方に届かないとき、ノルウェー気象研究所（MET Norway）の予報を使う。使わないなら `false` |
| 予報の保存 | `saveForecast: true` | 最後に取れた予報をテレビ内に保存し、再起動直後もそれで表示。使わないなら `false` |
| 新しい版への自動切り替え | `autoUpdate: true` | 公開中の版を1時間ごとに確かめ、番号が変わっていたら自動で読み直す。止めるなら `false` |
| 動作の記録の表示 | `logKeys: true` | リモコンの決定ボタン・方向ボタンで「動作の記録」を出す。出したくないなら `false`（記録そのものは続く） |
| 先の時間の雨の弱め方 | `rainFarHours: 6` | 発表から6時間より先の雨は、予報モデルのほうが弱いとき1段階弱く表示。弱めないなら `0` |
| 地点 | `placeName`, `lat`, `lon` | 別の場所に置くときは地名と緯度・経度を変える（気象庁の区域・市町村コード `jmaArea`, `jmaCity` も合わせて変更） |
| 版番号 | `version: '1.20'` | 画面右下に出る番号。差し替えのたびに上げる（テレビはこの番号の変化を見て自動で切り替わる） |

## 画面の確認用（URLの末尾に付ける。本番のURLには付けない）

- `?test=30` … WBGTの値を仮に30にして色を確認（WBGTは上段・表とも小数第1位を四捨五入した整数で表示・判定）
- `?wx=rain` … 天気を仮に雨にして背景を確認（sun / partly / cloud / fog / rain / snow / thunder）
- `?season=winter` … 冬季モード（体感温度）の見え方
- `?app=-3` … 体感温度を仮に-3℃にして色を確認
- `?warn=14,15` … 雷注意報・強風注意報が出たときの見え方（数字は気象庁のコード）
- `?alert=1` … 注意喚起のバッジを全部表示
- `?radar=0` … 「現在」にレーダー観測の小雨を表示（1なら1〜5mm）
- `?log=1` … 「動作の記録」をはじめから表示

## 画面右下の点（管理者向けの自己診断）

緑の点4つが正常。左から「予報・警報・レーダー・今後の雨」（「予報」は気象庁の予報と予報モデル〈Open-Meteo〉の両方）。一定時間取得できていないものは赤い点と名前で出ます（予報・警報は3時間、レーダーは20分、今後の雨は90分）。名前が赤く出続けるときは、ネット回線か、配信元側の停止・データの形式変更が考えられます。

点の左に黄色い文字が出るのは、プログラムの異常があるときだけです。「表示エラー」＝表示の途中で不具合が出た、「新しい版に誤りあり」＝公開中の index.html に文法エラーがあるため切り替えを見送っている。配信元への接続の失敗は画面には出さず（どこから取得しているかは、見出しの更新時刻の横の「（予備）」「（予備2）」で分かります）、理由は「動作の記録」に残ります。

## 止まったときの表示と対応

| 画面の表示 | 意味 | 対応 |
|---|---|---|
| 見出しが「更新 hh:mm（予備）」 | 通常の配信元が不調で、Open-Meteoの別サーバーから同じ予報を取得している | 不要（通常の配信元が戻れば自動で戻る） |
| 見出しが「更新 hh:mm（予備2）」、右下の出典が MET Norway | 通常・予備の両方が不調で、ノルウェー気象研究所の予報で表示している（「最高・最低」は出ない） | 不要（自動で戻る） |
| 見出しに「更新失敗 hh:mm・再試行中」 | 直前の取得に失敗した。数値は手元の予報で表示を続けている | 不要（30秒〜5分ごとに自動で再試行） |
| 中央に「最新の情報ではありません／最終更新 hh:mm」 | 更新が長く止まっている（テレビがネットにつながらない状態が2時間、または予報の配信元だけ止まって24時間） | 「動作の記録」で原因を確認。ネットにつながらないときはテレビの再起動（リモコンの電源ボタン長押し →「再起動」） |
| 中央に「情報を取得できていません」 | 起動してから30分以上、一度も予報を取得できていない | 同上 |
| 右下に「新しい版に誤りあり」 | 公開中の index.html に文法エラーがある（テレビは今の版で表示を続けている） | index.html を直して上書き |

## 動作の記録（止まった時刻と理由をあとから調べる）

テレビのリモコンの決定ボタン（または方向ボタン）を押すと、「動作の記録」が画面いっぱいに出ます（1分で消えます。決定ボタンでも消えます。下ボタンで古い記録へ）。写真に撮っておけば、止まった時刻と理由があとから分かります。記録はテレビの中に60件まで残り、再起動しても消えません。

| 記録の例 | 意味 |
|---|---|
| 起動 v1.20（前回の動作は 11/17 02:10 ごろまで） | ページが起動した。かっこ内は、その前にページが動いていた最後の時刻（空白が長ければ、その間は止まっていた） |
| 予報：予備で取得（通常:時間切れ） | 取得元が切り替わった。かっこ内は失敗した配信元と理由（時間切れ＝返事が遅い、不通＝つながらない、空＝中身が使えない、HTTP503 など＝配信元がエラーを返した） |
| 予報：取得できず（通常:不通 予備:不通 予備2:不通） | 3つとも失敗（失敗が続いても記録は1件） |
| 予報：通常で取得 | 通常の配信元に戻った |
| 中央に表示：最新の情報ではありません（ネットにつながらない） ／ 中央の表示が消えた | 画面中央の表示が出た・消えた時刻。かっこ内が原因（ネットにつながらない／予報の配信元が停止） |
| 画面が隠れた（別の画面・消灯など） ／ 画面が戻った | ページが見えない状態になった・戻った時刻 |
| 動きが止まっていた 11/17 02:13〜07:41 | その間、ページの動きが止まっていた（テレビの休止・固まりなど） |
| 回線が切れた ／ 回線が戻った | テレビが回線の切断・復帰を検知した |
| 新しい版 v1.20 を読み込み ／ 毎日の読み直し | 自動の読み直し |
| 表示エラー：… ／ エラー：… | プログラムの不具合（内容を控えて連絡） |
